# Lemonade Fizz Tech — Studio Site

The official website for Lemonade Fizz Tech, a web development studio. Built to showcase the studio's work and convert visitors into clients, with a focus on clean design and smooth, modern interactions.

**Live:** https://lemonadefizztech.com

## Tech Stack
- Next.js (App Router)
- Tailwind CSS
- Framer Motion (animations)
- Resend (contact form email delivery)
- Vercel (deployment)

## Features
- Fully responsive, mobile-first design
- Animated UI transitions with Framer Motion
- Working contact form with email delivery
- Fast performance, optimised for real-world networks
